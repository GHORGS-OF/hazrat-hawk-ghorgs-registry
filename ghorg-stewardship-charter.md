## Stewardship Principles

1. **Authenticate before mutating** — Verify actor, target, branch, worktree
2. **Inspect remote policy** — Read org metadata, templates, .github conventions
3. **Classify relationships** — Is this creation, adoption, contribution, or maintenance?
4. **Claim custody explicitly** — Record branch owner and worktree custodian
5. **Preserve identity separation** — Distinguish agent, session, branch owner, reviewer
6. **Leave evidence** — Other agents must continue without trusting conversation memory
7. **Handoff explicitly** — Name the next owner and continuation condition

## Hygiene Ritual

Before creating, adopting, or contributing to a repository:

```
resolve → inspect → classify → claim → mutate → verify → record → handoff
```
